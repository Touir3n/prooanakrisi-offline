# 🚔 Προανακριτική Μηχανή (Offline Edition)

Μια σύγχρονη, διαδικτυακή εφαρμογή (Web App) σχεδιασμένη αποκλειστικά για την υποβοήθηση του έργου των Προανακριτικών Υπαλλήλων. Σκοπός της εφαρμογής είναι η δραματική μείωση του χρόνου δακτυλογράφησης και η αυτοματοποίηση της σύνταξης δικογραφιών.

## 📌 Βασικές Λειτουργίες

- **🔄 Ανάλυση Στοιχείων (POL Integration):** Επικόλληση του κειμένου απευθείας από το σύστημα ταυτοτήτων (POL). Η εφαρμογή εξάγει και τοποθετεί αυτόματα όλα τα στοιχεία (Επώνυμο, Όνομα, Γονείς, Ημ. Γέννησης, ΑΔΤ, Διεύθυνση κλπ) στα σωστά πεδία.
- **🇬🇷 Έξυπνος Τοπικός Τονισμός & Πτώσεις:** Ενσωματωμένο τοπικό λεξικό με εκατοντάδες ονόματα, πόλεις και οδούς. Η εφαρμογή μετατρέπει αυτόματα τα κεφαλαία του συστήματος POL σε πεζά, βάζοντας τον σωστό τόνο και μετατρέποντας πατρώνυμα, μητρώνυμα και περιοχές στη **Γενική Πτώση** 100% τοπικά (χωρίς AI ή ίντερνετ).
- **📄 Γεννήτρια Προανακριτικών Εγγράφων:** Αυτόματη δημιουργία και λήψη εγγράφων σε μορφή Microsoft Word (`.doc`), έτοιμων για υπογραφή.
  - Ένορκη Εξέταση Μάρτυρα
  - Ενδοοικογενειακή Βία (Ν. 3500/06 - Ειδικό ερωτηματολόγιο & εξέταση χωρίς όρκο)
  - Προκαταρκτική Εξέταση (Γνωστοποίηση δικαιωμάτων, Ανωμοτί με/χωρίς προθεσμία, Εγχείριση Υπομνήματος)
  - Ροή Αυτοφώρου (Έκθεση Σύλληψης, Δικαιώματα Κατηγορουμένου, Απολογία)
  - Ναρκωτικά / Κατασχέσεις (Έκθεση Κατάσχεσης, Ζύγιση, Γνωστοποίηση)
- **⏱️ Έξυπνη Αλληλουχία Χρόνων:** Αυτόματος υπολογισμός των ωρών έναρξης/λήξης για κάθε διαδοχική έκθεση, προς αποφυγή δικονομικών σφαλμάτων.
- **✨ Μοντέρνα Εμφάνιση (Glassmorphism):** Φρέσκο και σύγχρονο περιβάλλον εργασίας με υποστήριξη για Φωτεινό (Light) και Σκοτεινό (Dark) θέμα, ιδανικό για πολύωρη χρήση.

## 🚀 Εγκατάσταση και Χρήση (Stand-Alone)

Δεν απαιτούνται δικαιώματα διαχειριστή (admin) ούτε εγκατάσταση πολύπλοκων προγραμμάτων:
1. Κατεβάστε τα αρχεία.
2. Κάντε διπλό κλικ στο αρχείο **`Εκκίνηση Προανακριτικής Μηχανής.bat`**. 
3. Το πρόγραμμα θα ανοίξει αυτόματα ως ανεξάρτητη εφαρμογή (PWA) μέσω του Google Chrome ή Edge.

## 🔐 Ασφάλεια Δεδομένων (100% Offline)
Η προστασία των Προσωπικών Δεδομένων είναι η απόλυτη προτεραιότητα αυτής της εφαρμογής:
- **100% Τοπική Λειτουργία:** Ολόκληρος ο κώδικας εκτελείται αποκλειστικά στον υπολογιστή σας. 
- **Καμία σύνδεση στο Internet:** Δεν απαιτείται internet, δεν υπάρχουν εξωτερικά API (ούτε AI), και **κανένα απολύτως δεδομένο δεν αποστέλλεται ποτέ σε κανέναν server**. 
- Όλα τα στοιχεία (ονόματα, ΑΔΤ, διευθύνσεις) παραμένουν αυστηρά και μόνο στη μνήμη RAM του δικού σας υπολογιστή, η οποία διαγράφεται όταν κλείσετε το πρόγραμμα.

## ⚠️ Αποποίηση Ευθύνης
Η εφαρμογή παρέχεται "ως έχει" (as-is). Αποτελεί αποκλειστικά εργαλείο παραγωγικότητας και **δεν υποκαθιστά την κρίση και την ευθύνη** του Προανακριτικού Υπαλλήλου. Ο τελικός χρήστης οφείλει να ελέγχει προσεκτικά τη νομική και γραμματική ορθότητα κάθε εγγράφου πριν την υπογραφή του.
